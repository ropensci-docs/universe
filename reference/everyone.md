# All universes

All universes

## Usage

``` r
everyone(type = c("all", "universes", "maintainers"))
```

## Arguments

- type:

  Type of universe to query: "all", only organizations ("universe"),
  personal accounts ("maintainer").

## Value

A character vector of all universes.

## Examples

``` r
if (FALSE) { # interactive()
head(everyone())
}
```
