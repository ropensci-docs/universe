# Package index

## Endpoint for global search across all universes

- [`global_search()`](https://docs.ropensci.org/universe/reference/global_search.md)
  : Search among all universes

## Endpoints for single universes

- [`everyone()`](https://docs.ropensci.org/universe/reference/everyone.md)
  : All universes
- [`universe_ls()`](https://docs.ropensci.org/universe/reference/universe_ls.md)
  : All packages in an universe
- [`universe_all_packages()`](https://docs.ropensci.org/universe/reference/universe_all_packages.md)
  : Info on all packages in an universe
- [`universe_one_package()`](https://docs.ropensci.org/universe/reference/universe_one_package.md)
  : Info on a single packages in an universe
- [`universe_search()`](https://docs.ropensci.org/universe/reference/universe_search.md)
  : Search within a single universe

## Utilities to manage universes

- [`use_universe_action()`](https://docs.ropensci.org/universe/reference/use_universe_action.md)
  : Use R-universe GitHub Actions workflow

- [`use_custom_manifest()`](https://docs.ropensci.org/universe/reference/use_custom_manifest.md)
  :

  Create `packages.json` for existing universe

## Utilities to handle local repositories

- [`add()`](https://docs.ropensci.org/universe/reference/add.md)
  [`remove()`](https://docs.ropensci.org/universe/reference/add.md) :
  Enable a package repository from r-universe
- [`repo_snapshot()`](https://docs.ropensci.org/universe/reference/snapshot.md)
  [`r_version()`](https://docs.ropensci.org/universe/reference/snapshot.md)
  : Download snapshot
