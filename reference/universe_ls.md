# All packages in an universe

All packages in an universe

## Usage

``` r
universe_ls(universe)
```

## Arguments

- universe:

  Name of the universe (character of length 1)

## Value

A character vector of all packages in the universe.

``` r
if (FALSE) { # interactive()
universe_ls("jeroen")

}
```
